DevEN Power System Simulation Platform

DevEN is an ultra-high performance, scriptable electric power grid simulation and analytics framework. Built with native C/C++ compiled mathematical kernels (.pyd) and an intuitive Python API, DevEN delivers lightning-fast computation for transmission, distribution, and industrial networks.

100 Bus Free Tier Included
Every DevEN distribution comes with an automatic 100 Bus Free Tier (mathematically supporting networks up to 101 buses without any license file). You can run all 4 analytical studies immediately with zero configuration!

The 4 Core Analytical Studies

⚡ 1. Load Flow (LFA)
High-speed AC power flow solving complex voltages, generator dispatch, branch power flows, losses, and reactive power limits.
💥 2. Short Circuit (SCS)
IEC 60909 / ANSI compliant fault study computing subtransient ($I_k''$), peak ($i_p$), breaking ($I_b$), and thermal equivalent currents.
🛡️ 3. Contingency Analysis (CA)
Exhaustive N-1 and N-2 transmission line & transformer outage screening with automated topology islanding detection and severity ranking.
⏱️ 4. Time-Series (TS-LFA)
Quasi-Static Time Series (QSTS) multi-period chronological simulation tracking renewable solar/wind generation and load diurnal profiles.

Complete 4-in-1 Script Example

Save the following script as run_grid.py and execute it with Python:

run_grid.py 
import deven

# 1. Initialize session and load a power grid case
sess = deven.DevENSession()
sess.load_case("cases/IEEE14BUS.py")  # or .raw, .dgs, .dat

# 2. Study 1: Run Newton-Raphson Load Flow
res_lfa = sess.run_lfa(method="nr", tol=1e-6)
print(f"LFA Converged: {res_lfa['converged']} in {res_lfa['iterations']} iterations")

# 3. Study 2: Run IEC 60909 Short Circuit at Bus 2
res_scs = sess.run_scs(fault_bus=2, fault_type="3phase")
print(f"Fault Current at Bus 2: {res_scs['fault_current_ka']:.2f} kA")

# 4. Study 3: Run N-1 Contingency Analysis
res_ca = sess.run_ca(scope="all_lines")
print(f"Contingencies Evaluated: {len(res_ca['contingencies'])}")

# 5. Study 4: Run 24-Hour Time Series Simulation
res_ts = sess.run_timeseries(steps=24)
print(f"Time-Series Total Energy Loss: {res_ts.get('total_loss_mwh', 0.0):.2f} MWh")

Load Flow Analysis (LFA) API

The Load Flow Analysis (LFA) engine computes the steady-state operating point of the AC power system. It calculates complex bus voltages ($V_i, \theta_i$), active and reactive branch power flows ($P_{ij}, Q_{ij}$), real power losses ($P_{loss}$), and generator reactive power dispatch ($Q_g$) under operational generator constraints.

Method Signature

Python Signature 
sess.run_lfa(
    method: str = "nr",
    tol: float = 1e-6,
    max_iter: int = 20,
    v_init: str = "flat",
    export_csv: Optional[str] = None,
    enforce_q_limits: bool = True
) -> Dict[str, Any]

Parameters & Options

Parameter Type Default Description
method str "nr" Solver algorithm: "nr" (Full Newton-Raphson), "fdlf" (Fast Decoupled XB/BX), or "gs" (Gauss-Seidel).
tol float 1e-6 Convergence tolerance for active and reactive power mismatch ($\Delta P, \Delta Q$) in p.u.
max_iter int 20 Maximum allowed iterations before aborting solver.
v_init str "flat" Voltage flat start configuration ("flat" sets 1.0 p.u. 0°, "previous" uses existing solution).
enforce_q_limits bool True Enforces generator reactive power bounds ($Q_{min} \le Q_g \le Q_{max}$), converting PV buses to PQ when violated.
export_csv str | None None Optional path to export solved bus and branch tables as formatted CSV files.

Return Dictionary Schema

Key Type Description
"converged" bool True if the solver achieved mismatch lower than tol; False otherwise.
"iterations" int Number of iterations executed to reach convergence.
"time_sec" float Total wall-clock execution time in seconds.
"buses" dict Dictionary keyed by bus_id with v_pu, angle_deg, p_gen, q_gen, p_load, q_load.
"branches" dict Dictionary keyed by branch_id with p_fwd, q_fwd, p_rev, q_rev, losses_mw, loading_pct.
"summary" dict System totals: total_gen_p, total_gen_q, total_load_p, total_load_q, total_loss_p, total_loss_q.

Code Example

run_lfa_example.py 
import deven

sess = deven.DevENSession()
sess.load_case("cases/IEEE14BUS.py")

# Execute Newton-Raphson Load Flow
res = sess.run_lfa(method="nr", tol=1e-6, max_iter=20)

if res["converged"]:
    print(f"Solved in {res['iterations']} iterations ({res['time_sec']:.4f}s)")
    for bus_id, b in res["buses"].items():
        print(f"Bus {bus_id:2d}: V = {b['v_pu']:.4f} p.u. | Angle = {b['angle_deg']:+6.2f}°")

Short Circuit Studies (SCS) API

The Short Circuit Study (SCS) solver implements rigorous fault calculations compliant with international standard IEC 60909 / VDE 0102 and ANSI/IEEE standards. It constructs positive, negative, and zero sequence impedance matrices ($Z^{(1)}, Z^{(2)}, Z^{(0)}$) to evaluate symmetrical and asymmetrical faults.

Method Signature

Python Signature 
sess.run_scs(
    fault_bus: Optional[Union[int, str]] = None,
    method: str = "iec",
    fault_type: str = "3phase",
    c_factor: float = 1.05,
    duration_s: float = 0.1,
    export_csv: Optional[str] = None,
    scope: str = "all_buses"
) -> Dict[str, Any]

Parameters & Options

Parameter Type Default Description
fault_bus int | str | None None Specific target bus for fault application. If None and scope="all_buses", runs batch faults across all buses.
method str "iec" Standard calculation method: "iec" (IEC 60909 equivalent voltage source) or "complete" (superposition).
fault_type str "3phase" Fault type: "3phase" (symmetrical three-phase), "1phase" / "lg" (single line-to-ground), "ll" (line-to-line), "llg" (double line-to-ground).
c_factor float 1.05 Voltage factor $c$: 1.05 or 1.10 for maximum short-circuit currents per IEC 60909 Table 1.
duration_s float 0.1 Fault clearing duration in seconds for thermal equivalent current ($I_{th}$) calculation.
scope str "all_buses" Batch scope: "all_buses" or "single".

Calculated Short-Circuit Quantities

Symbol Quantity Name Engineering Significance
$I_k''$ Initial Symmetrical Short-Circuit Current Determines RMS fault level at $t = 0$ for protective relay pickup and equipment breaking duty.
$i_p$ Peak Asymmetrical Current Highest instantaneous current peak ($kA$) governing dynamic electromechanical stress on busbars and switchgear.
$I_b$ Symmetrical Breaking Current RMS AC component at circuit breaker contact separation time ($t_{min}$).
$I_{th}$ Thermal Equivalent Current Effective joule-heating current ($kA$) governing conductor thermal withstand sizing.
$S_k''$ Initial Fault MVA Total three-phase short-circuit power level ($MVA$) at the substation bus.

Code Example

run_scs_example.py 
import deven

sess = deven.DevENSession()
sess.load_case("cases/IEEE14BUS.py")

# Run three-phase short-circuit analysis at Bus 1
res = sess.run_scs(fault_bus=1, fault_type="3phase", c_factor=1.05)

print(f"Fault Bus: {res['fault_bus']}")
print(f"Initial Current (Ik'') : {res['fault_current_ka']:.3f} kA")
print(f"Peak Current (ip)       : {res['peak_current_ka']:.3f} kA")
print(f"Breaking Current (Ib)   : {res['breaking_current_ka']:.3f} kA")
print(f"Fault Power (Sk'')      : {res['fault_power_mva']:.2f} MVA")

Contingency Analysis (CA - N-1 / N-2) API

The Contingency Analysis (CA) engine automates bulk $N-1$ and $N-2$ transmission line and transformer trip screening. It features high-speed graph topological island detection, solves post-contingency AC power flows, identifies cascading thermal overloads, and computes voltage severity ranking indices ($PI$).

Method Signature

Python Signature 
sess.run_ca(
    scope: str = "all_lines",
    rank_by: str = "overload",
    max_loading: float = 100.0,
    export_csv: Optional[str] = None,
    n_threads: int = 1
) -> Dict[str, Any]

Parameters & Options

Parameter Type Default Description
scope str "all_lines" Elements to trip: "all_lines", "all_transformers", or "all_branches".
rank_by str "overload" Ranking metric: "overload" (highest branch thermal %), "pi" (Performance Index), or "voltage_drop".
max_loading float 100.0 Thermal loading threshold percentage to flag an overload violation.
n_threads int 1 Number of parallel worker threads for parallel multi-core contingency screening.

Code Example

run_ca_example.py 
import deven

sess = deven.DevENSession()
sess.load_case("cases/IEEE14BUS.py")

# Run N-1 screening across all transmission branches
ca_res = sess.run_ca(scope="all_lines", max_loading=100.0)

print(f"Scanned {len(ca_res['contingencies'])} outage cases.")
for item in ca_res["worst_contingencies"][:5]:
    print(f"Outage [{item['tripped_element']}]: Max Loading = {item['max_loading_pct']:.1f}% on Line {item['overloaded_branch']}")

Time-Series Load Flow (TS-LFA) API

The Time-Series simulation engine performs chronological Quasi-Static Time Series (QSTS) simulations. It computes sequential AC power flows across user-defined time steps (hourly, 15-minute, or 1-minute intervals), tracking solar PV and wind generation variability, load demand diurnal profiles, and total system energy losses ($MWh$).

Method Signature

Python Signature 
sess.run_timeseries(
    steps: int = 24,
    step_size_s: float = 3600.0,
    profiles: Optional[Dict[str, Any]] = None,
    export_csv: Optional[str] = None,
    progress_bar: bool = True
) -> Dict[str, Any]

Parameters & Options

Parameter Type Default Description
steps int 24 Total number of simulation time intervals to execute.
step_size_s float 3600.0 Step duration in seconds (3600.0 = 1 hour, 900.0 = 15 minutes, 60.0 = 1 minute).
profiles dict | None None Profile multipliers for loads and renewables. Keyed by element or system-wide array.
export_csv str | None None Path to export time-series profile results table in CSV format.
progress_bar bool True Displays an interactive ASCII progress bar during multi-period solving.

Code Example

run_ts_example.py 
import deven

sess = deven.DevENSession()
sess.load_case("cases/IEEE14BUS.py")

# Execute 24-step chronological power flow
ts_res = sess.run_timeseries(steps=24, step_size_s=3600.0)

print(f"All 24 steps converged: {all(s['converged'] for s in ts_res['steps'])}")
print(f"Total Active Energy Loss : {ts_res['total_loss_mwh']:.2f} MWh")
print(f"Peak Power Loss          : {ts_res['peak_loss_mw']:.2f} MW")

Network Modeling & CRUD Operations

DevEN provides programmatic control to build power grids from scratch, clone existing components, modify operating points, or dynamically add renewable energy sources.

Element Creation API

build_grid.py 
import deven

sess = deven.DevENSession()
sess.new_case(name="Microgrid", base_mva=100.0)

# Add Substation Bus (Type 3 = Slack / Swing Bus)
sess.add_bus(bus_id=1, name="Grid_Infeed", base_kv=132.0, type=3)

# Add Distribution Bus (Type 1 = PQ Load Bus)
sess.add_bus(bus_id=2, name="Industrial_Park", base_kv=33.0, type=1)

# Add Step-down Transformer 132/33 kV
sess.add_transformer(xfmr_id=1, from_bus=1, to_bus=2, r=0.002, x=0.08, rateA=80.0)

# Add Heavy Industrial Load
sess.add_load(load_id=1, bus=2, P_demand=45.0, Q_demand=15.0)

# Solve Grid
res = sess.run_lfa()
print(f"Solved! Voltage at Bus 2: {sess.get_bus_voltage(2)[0]:.4f} p.u.")

Element Modification & Queries

queries.py 
# Update line rating or status
sess.set_line(line_id=12, rateA=250.0, status=1)

# Query line flow and loading
flow = sess.get_line_flows(line_id=12)
print(f"P = {flow['p_fwd']} MW | Loading = {flow['loading_pct']}%")

# Check voltage and thermal violations across entire network
viols = sess.get_violations(v_min=0.95, v_max=1.05, max_loading=100.0)
print(f"Voltage Violations: {len(viols['voltage_violations'])}")
print(f"Thermal Overloads : {len(viols['thermal_violations'])}")
