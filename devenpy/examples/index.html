DevEN

A high-performance power system study engine for loading electrical network models, configuring engineering studies, executing ultra-fast calculations, and extracting comprehensive results through the devenpy Python interface and standalone study runners.

Package: devenpyOrigin: Bengaluru, IndiaEngine: Rust Native SIMD & RayonContainer: PyCaseVersion: 1.0.0

RAWX Native PerformanceFirst-preference RAWX ingestion with instantaneous C-speed schema parsing and validation.

Installation & CLI Setup

Install the devenpy package directly from your wheel or repository:

pip install devenpy

Once installed, you can launch this interactive documentation locally or scaffold all study runners into your working directory with simple CLI commands:

# 1. Open this interactive documentation in your web browser (via local web server):
devenpy --docs

# 2. Export all 6 editable study runners, universal I/O parser, and benchmark grids directly to your current folder:
devenpy --export-runners

# You can also run via Python module:
python -m devenpy --docs
python -m devenpy --export-runners

Quick Start

Create a case, load a recommended .rawx network file, run an AC load-flow calculation and inspect the returned convergence status:

import devenpy

# Instantiate PyCase and load recommended RAWX network
case = devenpy.PyCase()
case.load_rawx("cases/bench.rawx")  # First preference: PSS/E RAWX

# Execute AC Newton-Raphson Load Flow
status = case.solve_load_flow(
    method="nr",
    tol=1e-5,
    max_iter=30,
    enforce_q_limits=True
)

print("Converged:", status["converged"])
print("Iterations:", status["iterations"])
print("Max |dP|:", status["max_dp"])

# Inspect bus voltage and power injection
v_mag, v_ang = case.bus_voltage(1)
p_inj, q_inj = case.bus_power(1)
print(f"Bus 1: V = {v_mag:.4f} pu, P = {p_inj:.2f} MW, Q = {q_inj:.2f} MVar")

Standalone Study Runners

DevEN includes 6 specialized, turnkey runner scripts designed for practical engineering workflows. Each script contains an editable in-code configuration block at the top, supports interactive file pasting, and outputs formatted console tables and CSV reports.

1. run_lfa.py — Load Flow Analysis

High-performance AC and DC power flow engine supporting Newton-Raphson, Fast Decoupled, DC Linear, Constant Jacobian, and Gauss-Seidel.

In-Code OptionAllowed ValuesDescription
METHOD"nr", "fdlf", "dc", "dishonest", "gs"Algorithm selection. Full NR is recommended for large grids.
TOLERANCE0.0001 / 1e-5Power mismatch convergence tolerance (p.u.).
MAX_ITER30 - 50Maximum iteration count before abort or fallback.
ENFORCE_Q_LIMITSTrue / FalseCheck generator reactive capability limits and convert PV buses to PQ when clamped.
CHECK_VOLTAGETrue / FalseScreen all buses for under/overvoltage against V_MIN_PU and V_MAX_PU.
CUSTOM_GEN_EDITSList of dictsIn-code modification of generator setpoints (pg, vs, qmax, qmin) before solve.
CUSTOM_LOAD_EDITSList of dictsIn-code modification of active and reactive load demands (pl, ql).
 
python run_lfa.py

2. run_scs.py — Short Circuit Studies (IEC 60909 / ANSI C37)

Calculates symmetrical and asymmetrical short-circuit currents, equivalent X/R ratios, circuit breaker duty ratings, and branch/generator fault contributions.

In-Code OptionAllowed ValuesDescription
STUDY_MODE"custom", "single", "scan"Run custom list of faults, single-bus fault, or system-wide scan across all buses.
CUSTOM_FAULTSList of dictsDefine multiple faults in code: bus, type (3phase, slg, ll, dlg), method (iec, ansi), rf, xf, cb_mva.
METHOD"iec" / "ansi"Standards: IEC 60909:2016 or ANSI/IEEE C37.010 / C37.5.
C_FACTOR1.10 / 1.00IEC voltage factor c (1.10 for maximum short-circuit current, 1.00 for minimum).
BREAKER_CHECKTrue / FalseEvaluates breaker duty percentage and CEA 80% safety margin.
 
python run_scs.py

3. run_bc.py — Batch Contingency & N-1 Outage Screening

Performs high-speed parallel N-1 contingency analysis across transmission lines, transformers, and generators, checking for post-contingency voltage collapse and violations.

In-Code OptionAllowed ValuesDescription
CONTINGENCY_MODE"custom", "auto", "both"Run user-defined outages in CUSTOM_CONTINGENCIES, full automated N-1 sweep, or both.
CUSTOM_CONTINGENCIESList of dictsDefine lines (from_bus, to_bus, ckt), transformers, and generator trips (bus, id).
METHOD"fdlf" / "nr"Fast Decoupled is recommended for sub-millisecond per-contingency screening.
V_MIN_PU / V_MAX_PU0.90 / 1.10Post-contingency voltage emergency limits.
 
python run_bc.py

4. run_ha.py — Harmonic Analysis & Resonance Frequency Scan

Calculates driving-point impedance profiles Z(f), identifies parallel resonance frequencies, solves multi-order harmonic penetration, and assesses IEEE 519 compliance.

In-Code OptionAllowed ValuesDescription
STUDY_TYPE"scan", "harmonics", "both"Execute frequency scan, multi-order harmonic flow, or both.
F_START_HZ / F_END_HZ50.0 / 2500.0Frequency sweep range (Hz) (up to 50th harmonic order).
CUSTOM_HARMONIC_SOURCESList of dictsInject harmonic current sources: bus, name, phase, i_fund_amps, ang_deg, spectrum_type (6pulse, 12pulse, custom).
CUSTOM_HARMONIC_FILTERSList of dictsInstall mitigation filters: bus, name, filter_type (single_tuned, high_pass), tuning_order, q_factor, mvar_rating.
THD_V_LIMIT_PCT5.0Maximum allowable bus voltage Total Harmonic Distortion (%) under IEEE 519.
 
python run_ha.py

5. run_3ph.py — Three-Phase Unbalanced Power Flow

Full phase-coordinate (ABC+N) load flow solver for unbalanced distribution networks, DER integration, and single-phase load studies.

In-Code OptionAllowed ValuesDescription
WIRE_CONFIG"4wire" / "3wire"4-wire system with explicit neutral conductor or Kron-reduced 3-wire.
METHOD"fcim" / "nr"Forward Current Injection Method or 3-phase Newton-Raphson.
CUSTOM_PHASE_LOADSList of dictsSpecify unbalanced phase loads: bus, pa_mw, qa_mvar, pb_mw, qb_mvar, pc_mw, qc_mvar.
MAX_VUF_PCT2.0IEEE 2% Voltage Unbalance Factor (V2/V1 %) compliance threshold.
 
python run_3ph.py

6. run_af.py — Arc Flash Hazard Analysis (IEEE 1584-2018)

Evaluates arcing current, incident energy, arc flash boundary, and required personal protective equipment (PPE) category per IEEE 1584-2018 and NFPA 70E-2024.

In-Code OptionAllowed ValuesDescription
STUDY_MODE"custom", "single", "scan"Evaluate custom equipment list, single bus, or all energized buses.
CUSTOM_ARC_FLASH_BUSESList of dictsDefine equipment: bus, config (vcb, vcbb, hcb, voa, hoa), working_dist_mm, gap_mm, clearing_time.
WORKING_DIST_MM457.2 / 610.0 / 914.4Working distance (18 inches for panels, 24 inches for switchgear, 36 inches for open yard).
CLEARING_TIME_SEC0.05 - 0.20Total protective relay tripping + circuit breaker clearing time.
 
python run_af.py

Calculates initial symmetrical short-circuit current ik_ka, peak making current ip_ka, symmetrical breaking current ib_ka, short-circuit power sk_mva, and equivalent xr_ratio.

Results, Queries & Export

Vectorized C-speed extraction of all bus voltages ('VM', 'VA') or branch flows across the entire network.

case.report_dict() · case.report_json()

Return complete simulation results (bus results, branch flows, generator outputs) as Python dict or serialized JSON.

case.write_out(path) · case.kcl_report(path)

Generate formatted columnar PSS/E reports (.out) and bus-by-bus active/reactive energy conservation balances (.kcl).

Master Command-Line Interface

The devenpy command line tool is built directly into the pip package and requires no external binaries:

# Scaffolding: Export all 6 runners into the active terminal folder
devenpy --export-runners

# Web Documentation: Launch interactive portal on local web server
devenpy --docs
devenpy --docs --port 8080

# Direct Simulations (RAWX First Preference)
devenpy cases/bench.rawx                                   # AC Load Flow (NR on RAWX)
devenpy cases/bench.rawx --study scs --scan                # Full system fault scan
devenpy cases/bench.rawx --format out -o output.out        # PSS/E columnar report
